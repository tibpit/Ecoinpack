# RedPen Profile

Brutally honest AI audit & rewrite of LinkedIn profiles, for the US market.

- **Free tier**: upload LinkedIn's "Save to PDF" export (or paste text) → 0–100 score + rewritten headline.
- **Paid tier ($19, one-time)**: full rewrite — About, every experience as copy-paste bullets, quick-wins checklist — delivered by email (Resend) and displayed on `/success`.

**Legal constraint baked in**: no scraping, no LinkedIn login. Input is user-uploaded only. Footer states "Not affiliated with LinkedIn Corporation".

## Stack

| Concern | Choice |
|---|---|
| Framework | Next.js 15 (App Router) + TypeScript + Tailwind CSS v4 |
| Hosting | **Cloudflare Workers** via the OpenNext adapter (`@opennextjs/cloudflare`) |
| AI analysis | Anthropic API, `claude-sonnet-4-6`, structured outputs validated with zod (`lib/schema.ts`) |
| Payment | Stripe Checkout, one-time $19 (fetch HTTP client + async SubtleCrypto webhook verification — Workers-compatible) |
| Email | Resend |
| Storage | **Cloudflare KV** only — no database in V1. Native 24h TTL (`expirationTtl`). The paid result is regenerated by the Stripe webhook from the uploaded text (KV id in the session metadata). |
| PDF parsing | `unpdf` (serverless build of pdfjs — runs on workerd, no DOM/canvas dependency) |

## Architecture / flow

```
/audit ── POST /api/analyze ──► rate limit (IP, 3/day)
                                ► PDF → text (unpdf) or pasted text
                                ► profile text → KV  profile:<uuid>  (TTL 24h, native)
                                ► Claude (claude-sonnet-4-6, JSON strict via zod)
                                ◄ FREE result: score + headline rewrite (rest stays server-side)

CTA ──── POST /api/checkout ──► Stripe Checkout session ($19, metadata = blobId)

Stripe ─ POST /api/stripe-webhook
                                ► verify signature (constructEventAsync + SubtleCrypto)
                                ► re-run FULL analysis from KV  profile:<blobId>
                                ► store result   KV  result:<session_id>  (TTL 24h)
                                ► send Resend email (copy-paste blocks + how-to guide)
                                ► delete  profile:<blobId>

/success?session_id=cs_... ──► polls GET /api/session-result
                                ► verifies payment with Stripe, returns the stored result
                                ► before/after diff + Copy buttons per section
```

KV keys use a UUID / the Stripe checkout session id, so they are unguessable; expiry is enforced natively by KV.

## Local development

```bash
cd redpen-profile
npm install
cp .env.example .env.local   # secrets for `next dev`
npm run dev                  # Next dev server (Node) — KV emulated via miniflare
```

To test in the **real Workers runtime** (workerd) — do this before deploying:

```bash
cp .dev.vars.example .dev.vars   # secrets for the workerd runtime
npm run preview                  # opennextjs-cloudflare build + wrangler dev
```

To receive Stripe webhooks locally:

```bash
stripe login
stripe listen --forward-to localhost:8787/api/stripe-webhook   # 3000 for `next dev`
# copy the printed whsec_... into .dev.vars (and .env.local)
```

Test a payment with card `4242 4242 4242 4242`, any future date, any CVC.

## Deploying on Cloudflare Workers

1. **Authenticate wrangler**: `npx wrangler login` (or set `CLOUDFLARE_API_TOKEN`).
2. **KV namespace**: `wrangler.jsonc` already references the `redpen-profile` namespace (binding `REDPEN_KV`, id `1748bda933a14e3e967dcc403d9c6b8d`). On another account, create one with `npx wrangler kv namespace create redpen-profile` and update the `id`.
3. **Secrets** (prompted interactively, stored encrypted):
   ```bash
   npx wrangler secret put ANTHROPIC_API_KEY
   npx wrangler secret put STRIPE_SECRET_KEY
   npx wrangler secret put STRIPE_WEBHOOK_SECRET   # after step 6
   npx wrangler secret put RESEND_API_KEY
   ```
4. **Vars**: in `wrangler.jsonc` → `vars`, set `NEXT_PUBLIC_APP_URL` (production URL, no trailing slash) and `RESEND_FROM_EMAIL` (verified Resend sender).
5. **Deploy**: `npm run deploy`. First deploy gives you the `https://redpen-profile.<account>.workers.dev` URL — put it in `NEXT_PUBLIC_APP_URL` and redeploy (or attach a custom domain in the dashboard first).
6. **Stripe webhook**: Stripe dashboard → *Developers* → *Webhooks* → *Add endpoint*:
   - Endpoint URL: `https://<your-domain>/api/stripe-webhook`
   - Events: `checkout.session.completed` (only this one is needed)
   - Copy the *Signing secret* (`whsec_...`) into `wrangler secret put STRIPE_WEBHOOK_SECRET`.
7. **Resend**: verify your sending domain in Resend, then use an address on it in `RESEND_FROM_EMAIL`.
8. **Plan**: use Workers Paid ($5/month). The free plan's 10 ms CPU limit is too tight for PDF parsing; the paid plan's 30 s CPU default is ample (waiting on the Claude API costs ~0 CPU, and there is no wall-clock limit).

## V1 limitations (intentional)

- **Rate limiting** (`lib/rate-limit.ts`) is in-memory: on Workers it applies per isolate, not globally. Acceptable as an abuse brake at launch; move the counter to KV or a Durable Object for a hard guarantee.
- The free analysis already runs the full model call but only returns score + headline to the client; the paid content never reaches the browser before payment.
- The Stripe webhook does the full analysis + email inline (≈30–60 s). Stripe tolerates this but may retry on slow responses; delivery is idempotent on the result (same KV key) though a retry could re-send the email. Move the work to a Cloudflare Queue if this ever becomes an issue.

## Where things live

| Path | Role |
|---|---|
| `wrangler.jsonc` | Workers config: KV binding, vars, `nodejs_compat` |
| `open-next.config.ts` | OpenNext adapter config |
| `lib/prompts.ts` | Claude system prompt (banned buzzwords, evidence rule, scoring rubric) |
| `lib/schema.ts` | zod schema of the strict JSON output |
| `lib/claude.ts` | Anthropic call (`messages.parse` + `zodOutputFormat`) |
| `lib/storage.ts` | Cloudflare KV put/read/delete (native 24h TTL) |
| `lib/rate-limit.ts` | IP limiter, 3/day |
| `lib/email.ts` | Resend result email (copy-paste blocks + application guide) |
| `app/api/*` | analyze, checkout, stripe-webhook, session-result |
| `app/page.tsx` | Landing (placeholder respecting the charter — swap in the final mockup) |
| `app/audit/page.tsx` | Upload/paste → free result + blurred paid sections + CTA |
| `app/success/page.tsx` | Post-payment: polls the result, before/after diff, Copy buttons |
